## Overview

This project demonstrates a reproducible base-R workflow for exploring a **synthetic campus study-room dataset**. The analysis validates booking records, calculates completed room-hours and student-hours, summarizes usage by room type and time slot, and produces a chart of completed room-hours by room type.

## Synthetic Dataset

The dataset contains 24 fictional study-room bookings. It does not contain student names, email addresses, identification numbers, or other personal information.

| Variable | Type | Description |
|---|---|---|
| `booking_id` | Character | Unique synthetic booking identifier |
| `booking_date` | Date | Fictional reservation date |
| `time_slot` | Character | Morning, Afternoon, or Evening |
| `room_type` | Character | Small, Medium, or Large room |
| `group_size` | Integer | Fictional number of students booked |
| `duration_hours` | Numeric | Reserved duration in hours |
| `status` | Character | Completed, Cancelled, or No-show |

## Example Usage

Run the analysis from the repository root:

```r
source("scripts/study_room_analysis.R")
```

The script will:

1. import and validate the synthetic booking records;
2. retain completed bookings for utilization summaries;
3. calculate completed room-hours and student-hours;
4. summarize usage by room type and time slot;
5. write two summary tables to `outputs/`; and
6. create `outputs/completed_room_hours.png`.

Open `study_room_documentation.Rmd` in RStudio or Posit Cloud to review the documented workflow and select **Knit** to generate the formatted output.

## Generated Outputs

After a successful R run, the `outputs` folder should contain:

- `completed_room_hours.png`

## Limitations

- The data are fictional and cannot support conclusions about real students or facilities.
- Room-hours describe completed reservations, not actual minute-by-minute occupancy.
- Student-hours are an exposure measure, not evidence of academic performance.
- The analysis is descriptive and does not establish causation or predict demand.
